# Слой за слоем

Веб-приложение для телефона, планшета и компьютера: паспорт скрытых коммуникаций. Снимки стен до отделки, трассы, совмещение с готовой стеной, проверка точки перед сверлением. Данные хранятся только на устройстве.

Версия 7.0. Запускается с HTTPS (например, GitHub Pages) вместе со всеми файлами из репозитория.
